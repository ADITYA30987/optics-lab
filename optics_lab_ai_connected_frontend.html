Optics equation

GAUSSIAN FORM
1/f = 1/s + 1/s′
s is signed object distance; s′ is signed image distance in the physical convention used here.
Sign convention used
Real object distance s is positive; virtual object distance s is negative. Converging element f is positive; diverging element f is negative. Positive image distance means real image.
